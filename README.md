# Computer Networking Labs

A collection of basic computer networking labs completed to develop practical knowledge of network configuration, IP addressing, and routing protocols.

## Labs

- **LAN Configuration:** Basic LAN topology, device connections, IP addressing, and connectivity testing.
- **DHCP Configuration:** Automatic IP address assignment to client devices.
- **RIP Routing:** Configuring RIP to enable communication between different IP networks.
- **OSPF Routing:** Configuring OSPF for routing between multiple networks.

## Tools and Technologies

- Cisco Packet Tracer (if used)
- IPv4 Addressing
- LAN and Switching
- DHCP
- RIP
- OSPF

## Learning Objectives

- Understand basic network topologies.
- Configure IP addresses and DHCP.
- Practice dynamic routing protocols.
- Test network connectivity and troubleshoot configuration issues.
